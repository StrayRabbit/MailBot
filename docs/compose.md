# 邮件编辑

在 **邮件** 页编辑主题、HTML 正文和附件。点右下 **保存配置** 后才会写入数据库；点 **开始** 前必须先保存，否则主循环拿不到模板。

![邮件页](images/compose.png)

---

## 1. 主题

### 字段

单行文本框，必填。

### 校验

保存时 `MailTemplate.IsValid()` 会校验：

- 不能为空。
- 不能含 `\r` 或 `\n`（**防 SMTP 头注入**：攻击者用 `Subject: foo\r\nBcc: attacker@evil.com` 偷塞 BCC）。
- 不能含 `\0`（NUL 字符）。
- 其他控制字符同样会被拒绝。

校验失败会弹窗提示，但**不会自动清空**内容，请按提示手动修改。

---

## 2. 正文

### 工具栏

富文本编辑器，提供 4 个快捷按钮：

| 按钮 | 行为 |
|---|---|
| `B` | 加粗 |
| `I` | 斜体 |
| `U` | 下划线 |
| `🔗` 超链接 | 插入链接（弹窗输入 URL，会插入 `<a href="...">link</a>`） |

底层实现是 WPF `WebBrowser` 控件 + `contenteditable`，最终以 HTML 字符串形式保存。

### 行为说明

- 编辑器显示的是"渲染后"的 HTML（所见即所得）。
- 你可以粘贴来自 Word / 浏览器 / 其他富文本编辑器的复杂 HTML，但**样式可能不完全保留**（取决于粘贴内容结构）。
- 顶部格式化按钮作用于**当前光标选区**。
- 底部不会出现"源代码编辑"按钮；如需直接编辑 HTML，请改数据库 `app_config` 表的 `mail_body` 字段。

### 校验

- 不允许空 `<body>`（必须有可见文字或图片或链接）。
- 保存时同样过滤 `\r\n\0` 与控制字符。

### 推荐内容

- 简单一段话 + 一两个链接，比复杂排版更不容易被识别为群发。
- 避免大字体 + 多色 + 多图 + 表情混用 —— 这是垃圾邮件的典型特征。
- 避免"完全无正文 + 只有大附件" —— 多数邮件客户端会判定为可疑。
- 主题和正文都尽量避免营销敏感词（"免费"、"中奖"、"促销"、"立即购买"等）。

## 3. 附件

### 添加

点 **+ 添加附件** → 系统对话框选文件 → 文件被**复制**到 `<db 父目录>/attachments/`。

复制的目的：

- 原文件被删除/移动/重命名不会影响已发送邮件（MimeKit 已经引用的是复制路径）。
- 多台机器间复制 MailBot 数据目录时附件会一并带走。

### 删除

勾选列表中的附件 → 点 **删除选中** → 物理删除 `<db 父目录>/attachments/` 里的副本。

> ⚠️ 删除附件**不可恢复**。如已发出的邮件引用了已删除的附件，收件人那边仍能看到（因为邮件里嵌的是发送时刻的快照）—— 只是你下次编辑时本地不再有这个附件的副本。

### 列表

附件列表显示**绝对路径**（如 `D:\AppData\MailBot\attachments\release-notes.pdf`）。这是设计如此，方便定位。

### 大小限制

没有 UI 上的大小限制，但 SMTP 服务商通常有单封邮件总大小上限（常见 25MB）。超大附件会触发 SMTP 失败。

## 4. 模板组装

保存时构造 `MailTemplate { Subject, HtmlBody, AttachmentPaths }` 并写入 `app_config` 表：

```
mail_subject      →  主题字符串
mail_body         →  HTML 正文
mail_attachments  →  附件绝对路径 JSON 数组（每行一项）
```

主循环开始时从 `app_config` 加载这个 `MailTemplate`。

> 💡 修改模板后**不必重启 MailBot**，下次点 "开始" 会用最新的模板；但已经在跑的批次用的是点开始时锁定的模板。

---

## 5. 邮件装配逻辑（MailBuilder）

每批发送时 `MailBuilder.BuildForRecipients(sender, template, recipients, verifierBcc)` 决定 To / Bcc / Verifier：

| 收件人数 | To | Bcc | 验证邮箱 |
|---|---|---|---|
| 1 | 该收件人 | （空） | verifierBcc（如有） |
| ≥ 2 | 第 1 个收件人 | 其余收件人 + verifierBcc（如有） | （同 Bcc） |

`verifierBcc` 来自所有**已启用**的验证邮箱（轮流取）。

主题**不带** `[batch=xxx]` 前缀（早期设计曾带，后移除以避免被反垃圾检测命中）。

---

## 6. 保存配置按钮

右下角 **保存配置** 触发：

1. 校验主题和正文。
2. 校验附件路径存在。
3. 把 `MailTemplate` 序列化进 `app_config` 表。
4. 顶部状态栏短暂显示 "已保存"。

如果校验失败，按钮不变灰也不会清空内容，弹窗告诉你错在哪。
