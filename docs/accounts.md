# 账号管理

MailBot 区分两种账号：

- **发件账号** —— 通过 SMTP 协议**发送邮件**。
- **验证邮箱** —— 通过 IMAP 协议**拉取收件**，用来验证"我刚发的邮件确实被收件方服务器接收了"。

两者在 **账号** 页分开管理。验证邮箱是可选的。不配的话系统进入**无验证模式**：SMTP 返回 250 OK 就直接算送达，状态落「已送达」，队列正常推进到下一批。代价是失去真实投递确认 —— 对方服务器拒收、SMTP 谎报成功这类情况你察觉不到。

## 1. 发件账号（SMTP）

点 **+ 添加账号** → 在弹窗里填写。

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 邮箱 | ✓ | 收件人看到的发件人地址 |
| SMTP 主机 | ✓ | 邮件服务商提供的发件服务器域名，如 `smtp.gmail.com` / `smtp.qq.com` / `smtp.exmail.qq.com` |
| SMTP 端口 | ✓ | **465** = 隐式 SSL（连接即 TLS）；**587** / **25** = STARTTLS（连接后升级 TLS）。MailBot 按端口自动选择，**不是看 UI 里的"SSL" 复选框** |
| 用户名 | ✓ | 大多数情况下等于邮箱地址 |
| 密码 | ✓ | 见下方"密码是什么" |
| 日配额 | ✓ | 该账号今日最多发送封数；过 0 点自动重置 |
| 状态 | 自动 | `正常` / `冷却中` / `已封禁`，由系统设置 |
| 连续失败 | 自动 | 自上次成功以来的连续失败次数 |
| 冷却到期 | 自动 | 若处于冷却中，显示解除时间 |
| 信任无效证书 | ✗ | 自建邮箱或证书过期时勾上，否则 SMTP 连接会因证书校验失败而中断 |

### 密码是什么（重要！）

不同邮件服务商对"密码"的定义完全不同：

| 服务商 | 填什么 | 备注 |
|---|---|---|
| **QQ 邮箱** | **授权码**（16 字符） | 登录密码不行。QQ 设置 → 账户 → POP3/IMAP/SMTP/Exchange/CardDAV/CardDAV服务 → 开启 IMAP/SMTP 服务 → 生成授权码 |
| **163 邮箱** | **授权码**（客户端授权密码） | 设置 → POP3/SMTP/IMAP → 开启 + 设置授权码 |
| **Gmail** | **应用专用密码**（16 字符） | 需先开启两步验证，再去 https://myaccount.google.com/apppasswords 生成 |
| **Outlook / Office 365** | **账户密码**或**应用密码** | 取决于是否开启 MFA |
| **自建邮箱（Postfix/Exchange 等）** | **账户密码** | 可能需要勾"信任无效证书" |

⚠️ **填错了会得到 `AuthFailure` 错误码**，账号被立刻冷却。

### 状态机

发件账号有 3 种状态：

```
            连续失败达 阈值                    冷却到期 / 手动 解除封禁
  ┌───────┐ ─────────────→ ┌──────────┐ ─────────────────────→ ┌──────┐
  │ 正常  │                 │ 冷却中   │                          │ 正常 │
  └───────┘ ←────────────── └──────────┘                          └──────┘
            手动 解除封禁 / 重置配额
       ┌─────────┐
       │ 已封禁  │ ← 手动标记为封禁
       └─────────┘
```

- **正常**：可被主循环选中发送。
- **冷却中**：剩余 `冷却时长` 分钟内不可被选中，到期自动恢复"正常"。
- **已封禁**：永久不可被选中，只能通过"解除封禁"手动恢复。账号编辑对话框里有"解除封禁"按钮。

### 操作按钮

- **+ 添加账号**：新增。
- **编辑**：修改任意字段（包括日配额）。状态字段也可手动覆盖。
- **解除封禁**：把 `已封禁` 状态改回 `正常`。
- **删除**：从数据库移除该账号（**其历史发送日志和配额退额审计保留**）。

## 2. 验证邮箱（送达验证）

点 **+ 添加验证邮箱** → 在弹窗里填写。

### 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 邮箱 | ✓ | 用于接收自己发出的 BCC 邮件；**应配置至少 1 个** |
| IMAP 主机 | ✓ | 如 `imap.qq.com` / `imap.gmail.com` |
| IMAP 端口 | ✓ | 几乎都是 `993`（隐式 SSL） |
| 用户名 | ✓ | 通常等于邮箱 |
| 密码 | ✓ | 同发件账号的"密码"原则 —— QQ/163 邮箱是**授权码** |
| 启用 | ✓ | 取消勾选 = 临时禁用（不删除配置） |

### 它怎么工作（简化版）

每次主循环发出一批 BCC 邮件后，验证 Worker 会：

1. 等 `重查间隔` 秒（默认 120s）—— 给收件方邮件服务器一点时间接收。
2. 在每个**启用**的验证邮箱上 IMAP 查询过去 `时间窗`（默认 1 小时）内的邮件。
3. 找到 `From` 与该批次发件账号匹配、`Envelope.From` UID 唯一的邮件 → 标记批次 `已送达`。
4. 达到 `轮询次数`（默认 3 次）仍未命中 → 标记批次 `未确认`，回退收件人为 `pending`，对发件账号施加 `未确认冷却`（默认 60 分钟）。

> 💡 **建议配置 2 个不同域名的验证邮箱**（如 1 个 QQ + 1 个 163）。某个域名临时故障时另一个能继续验证。

### 操作按钮

- **+ 添加验证邮箱**：新增。
- **编辑**：修改任意字段，或临时勾掉"启用"。
- **删除**：从数据库移除。

## 3. SSL / 端口选择规则

MailBot 按 **SMTP 端口号**自动选择 TLS 模式，**不读取 UI 上的 SSL 复选框**（这是内部约定）：

| 端口 | TLS 模式 |
|---|---|
| `465` | 隐式 SSL（连接即 TLS） |
| `25` / `587` / 其他 | STARTTLS（连接后 `STARTTLS` 命令升级） |

IMAP 端口选择同上：`993` = 隐式 SSL；`143` = STARTTLS。

## 5. 常见邮件服务配置速查

| 服务商 | SMTP 主机 | SMTP 端口 | IMAP 主机 | IMAP 端口 | 密码类型 |
|---|---|---|---|---|---|
| QQ 邮箱 | `smtp.qq.com` | `465` | `imap.qq.com` | `993` | 授权码 |
| 163 邮箱 | `smtp.163.com` | `465` 或 `994` | `imap.163.com` | `993` | 授权码 |
| 126 邮箱 | `smtp.126.com` | `465` 或 `994` | `imap.126.com` | `993` | 授权码 |
| Gmail | `smtp.gmail.com` | `587`（推荐）或 `465` | `imap.gmail.com` | `993` | 应用专用密码 |
| Outlook | `smtp.office365.com` | `587` | `outlook.office365.com` | `993` | 账户密码 / 应用密码 |
| 自建（Postfix 等） | 你的主机 | `465`/`587`/`25` | 你的主机 | `993`/`143` | 账户密码（可能需勾"信任无效证书"） |

> 📌 截图里的 `sender@example.com` 为自建邮箱经 SMTP 服务商转发的示例；实际部署请替换为你的服务商配置。
