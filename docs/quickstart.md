# 快速上手（首次使用流程）

本节带你走完一个完整的"从安装到发出第一封邮件"的流程，每一步都配图。

> **约定**：
> - 截图里的"当前账号"、"已发/配额"、"待发送"等数字仅作示意，以你自己的数据为准。
> - 截图里出现的邮箱地址（如 `sender@example.com`、`verifier@example.com`）为示例配置，请按你自己的账号信息填写。
> - QQ 邮箱、163 邮箱等国内邮箱**必须使用授权码**，不能填登录密码。详见 [accounts.md](accounts.md)。

---

## 第 1 步：启动应用

直接双击 `MailBot.App.exe`，或：

```bash
dotnet run --project src/MailBot.App/MailBot.App.csproj
```

首次启动会：

1. 在 `%AppData%\MailBot\` 下创建 `mailbot.db`（SQLite）。
2. 创建 `logs/` 和 `attachments/` 子目录。
3. 自动运行 Schema 迁移（如果是旧库会补字段）。
4. 显示主窗口并在系统托盘放置一个紫色信封图标。

> 💡 启动第二份 MailBot 实例不会有任何窗口弹出 —— 第二进程会通过命名管道通知已运行的实例显示主窗口后退出。

![主窗口](images/main-window.png)

主窗口分 3 块：

- **顶部工具栏**：开始 / 暂停 / 停止按钮 + "当前账号" + "今日已发"。今日已发的口径与统计页"今日"柱一致：今天已通过 IMAP 验证的收件人数（`recipients.status='verified'`）。当前账号配额在本页内 "账号配额: X / Y" 行查看。
- **左侧导航**：监控 / 账号 / 收件人 / 邮件 / 调度 五个页面。
- **底部状态栏**：最近一次发送结果摘要。

---

## 第 2 步：添加发件账号（账号页）

切换到 **账号** 页 → 点 **+ 添加账号**，弹出"发件账号"对话框。

按 [accounts.md](accounts.md) 的字段表填写：

| 字段 | 示例 | 说明 |
|---|---|---|
| 邮箱 | `yourname@yourdomain.com` | 收件人看到的发件人 |
| SMTP 主机 | `smtp.yourdomain.com` | 邮件服务提供方给的值 |
| SMTP 端口 | `465` | 465 = 隐式 SSL；其他常见端口 25/587 走 STARTTLS |
| 用户名 | `yourname@yourdomain.com` | 通常等于邮箱 |
| 密码 | `********` | 多数邮箱服务是授权码，不是登录密码 |
| 日配额 | `350` | 今日最多发送封数（默认 50） |
| 信任无效证书 | ☐ | 自建邮箱、证书过期时勾上 |

填完保存，回到账号页会看到账号出现在"发件账号"列表里。

![账号页](images/accounts.png)

> ℹ️ **添加 1 个发件账号就够了**。多账号是用于"主账号被封/冷却后自动切换到备用"，不是必须。

---

## 第 3 步：添加验证邮箱（账号页）

同一个 **账号** 页下半部分是"验证邮箱（送达验证）"。点 **+ 添加验证邮箱**，弹出"验证邮箱"对话框。

| 字段 | 示例（QQ 邮箱） | 说明 |
|---|---|---|
| 邮箱 | `verifier@qq.com` | 用于 BCC 接收自己发的邮件 |
| IMAP 主机 | `imap.qq.com` | |
| IMAP 端口 | `993` | 几乎都是 993（隐式 SSL） |
| 用户名 | `verifier@qq.com` | |
| 密码 | `********` | **QQ 邮箱此处是授权码**（不是登录密码） |
| 启用 | ☑ | 暂不启用可取消勾选 |

> ⚠️ QQ 邮箱需要在"设置 → 账户 → POP3/IMAP/SMTP/Exchange/CardDAV/CardDAV服务"中**手动开启 IMAP/SMTP 服务**并生成**授权码**。操作详见 https://service.mail.qq.com/detail/0/75

---

## 第 4 步：导入收件人（收件人页）

切换到 **收件人** 页 → 点 **导入 Excel/CSV**。

文件要求：

- 列至少含 `email`（其他列会被忽略）。
- 支持 BOM 自动识别编码：UTF-8、UTF-16 LE、UTF-16 BE；其他情况按 UTF-8 尝试。
- 首行如果是表头（含"email"字样）会被识别为表头；首行直接是数据（如 `xxx@example.com`）则视为无表头。

> 💡 一行只放一个邮箱最简单。如果你的 Excel 里有"姓名 + 邮箱 + 公司"等多列，只要保证有一列叫 `email` 即可，其他列会被忽略。

导入完成后列表会显示所有收件人，状态默认为 `待发送`。

![收件人页](images/recipients.png)

底部翻页控件：每页 50 条（默认），可改 [docs/development.md](development.md) 中的 `PageSize` 常量。

---

## 第 5 步：编辑邮件内容（邮件页）

切换到 **邮件** 页。

![邮件页](images/compose.png)

- **主题**：必填，会经过 SMTP 头注入校验（禁止 `\r \n` 和 NUL 字符）。
- **正文**：富文本编辑器（`B` 加粗、`I` 斜体、`U` 下划线、`🔗` 超链接）。底层是 HTML，最终以 HTML 形式发送。
- **附件**：点 **+ 添加附件** 选择本地文件，文件会被**复制到 `<db 父目录>/attachments/`**，原文件后续被删/移动不影响已发送邮件；点 **删除选中** 移除。

填完点右下 **保存配置** 写入数据库。

---

## 第 6 步：调整调度参数（调度页）

切换到 **调度** 页。默认参数通常已经够用，先按需微调：

![调度页](images/schedule.png)

**发送调度**

| 字段 | 默认值 | 含义 |
|---|---|---|
| 窗口 | `00:00 - 23:59` | 发送时间窗口，支持跨天（如 `22:00 - 06:00`）。窗口外主循环睡眠到下次起点 |
| 批间隔 | `600 秒` | 上一批 SMTP 200 OK 后等多久再发下一批 |
| 批大小 | `20` | 每批 BCC 收件人数。SMTP 单封 BCC 越多越容易被识别为群发 |
| 冷却阈值 | `3` | 连续失败多少次后该账号进入 cooling |
| 冷却时长 | `60 分钟` | cooling 状态持续时间 |
| 最大重试 | `1` | 单封失败重试次数 |

**送达验证时间**

| 字段 | 默认值 | 含义 |
|---|---|---|
| IMAP 轮询间隔 | `60 秒` | 验证 Worker 主循环醒的频率 |
| 重查间隔 | `120 秒` | 批次发送后等多久才进入首查 |
| 轮询次数 | `3 次` | 达到此次数仍未命中 → 判定未确认 |
| 时间窗 | `1 小时` | 每次 IMAP 只查过去此范围内的邮件 |
| 未确认冷却 | `60 分钟` | 批次未确认后对该发件账号的冷却时长 |
| 上一批验证等待 | `300 秒` | 旧字段，保留以兼容旧配置，新逻辑不再使用 |

详细字段含义和校验规则见 [schedule.md](schedule.md)。

改完点右下 **保存配置**。

---

## 第 7 步：开始发送

回到顶部工具栏，点 **开始**。

- "开始" 会在内存中构造一个 `MailTemplate`（主题+HTML+附件路径），启动 `SendEngine` 主循环。
- "暂停" / "停止" 在引擎运行时才可点。
- 主循环会做这些事：
  1. 检查是否在发送窗口内（窗口外睡到下次起点）
  2. 检查是否还有 `pending` 状态的收件人（没有则 Completed）
  3. 从发件账号池挑选最佳账号（排除被封/冷却/配额用尽）
  4. 取一批（默认 20 个）收件人
  5. 组装邮件（1 个 To + 其余 BCC + verifier BCC），SMTP 发送
  6. 写入发送日志，按"批间隔"等待下一批

---

## 第 8 步：查看监控（监控页）

切换到 **监控** 页查看实时状态。

![监控页](images/monitor.png)

页面分 3 个区块：

- **实时监控**：5 个统计卡片 —— 待发送 / 验证中 / 今日已发 / 已送达 / 未送达/失败。下方一行显示当前账号的配额/冷却/状态进度条、下一批预计发送时间、当前批次收件人数和封 BCC 数。
- **收件人状态（最近）**：最近 20 个收件人及其状态。
- **日志**：彩色实时日志流，时间戳 + 符号（✓ ✓ ⏳ ✗ 等）+ 文本。

---

## 第 9 步：关闭窗口

点右上角 ✕，会弹窗：

> 关闭 MailBot 时希望如何处理？
>
> - **是** = 最小化到托盘，后台继续运行
> - **否** = 真正退出应用

托盘图标 = 系统托盘里的紫色信封。右键菜单：**显示主窗口** / **退出**。

> 💡 窗口被误关时，托盘还在，双击托盘图标即可恢复。
